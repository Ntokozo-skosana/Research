# Raw Data

## Overview

This directory is reserved for the original HAALSI source datasets used in this research project.

The raw HAALSI datasets are not included in this repository because they are subject to data-access, privacy and usage restrictions.

## Data Access

Researchers wishing to reproduce this research must obtain authorised access to the relevant HAALSI datasets through the official data provider.

The source datasets used during this research include:

- HAALSI Dementia Wave 1
- HAALSI Dementia Wave 2
- HAALSI Wave 2 Survey
- HAALSI Wave 3 Survey (longitudinal dataset)

The exact source files, variable descriptions and relevant release information are documented in `docs/SOURCE_DATA_REGISTER.md`.

## Directory Structure

After obtaining authorised access, place the required source files in this directory, following the filenames and folder structure expected by the data-processing scripts.

## Important Notes

- Raw participant-level data must not be committed to this repository.
- Do not upload restricted HAALSI datasets to public GitHub repositories.
- Researchers are responsible for obtaining the necessary permissions before accessing or using the data.
- The processing scripts require the original source datasets to be available locally.

This repository provides the research code and documentation but does not distribute the original HAALSI data.
