# Experiment guide and rerun commands

Run commands from the project root. Use a virtual environment and install the dependencies listed in `requirements.txt`. The recorded manifests show Python 3.14.0 and package versions including scikit-learn 1.9.0, XGBoost 3.4.1, PyTorch 2.14.1+cpu, pandas 2.3.3, NumPy 2.4.3, and SHAP 0.54.1. Check package availability for your operating system before installation.

## 0. Dataset preflight

`dataset_preflight.py` is a helper module imported by the training scripts; it is not a standalone command-line program. Each relevant training script invokes its integrity checks automatically.

## 1. Baseline-adjusted Ridge and Random Forest (Stage 2)

```powershell
py scripts/train_baseline_adjusted.py --data .\data\processed\haalsi_404_cleaned.csv --out .\results\results_cleaned_stage2
```

## 2. XGBoost and sleep-domain ablations (Stage 3)

```powershell
py scripts/train_stage3_xgboost.py --data .\data\processed\haalsi_404_cleaned.csv --out .\results\results_cleaned_stage3 --stage2-predictions .\results\results_cleaned_stage2\out_of_fold_predictions.csv
```

## 3. LSTM/GRU sequence models (Stage 4)

```powershell
py scripts/train_stage4_sequences.py --data .\data\processed\haalsi_404_cleaned.csv --out .\results\results_cleaned_stage4 --stage2-predictions .\results\results_cleaned_stage2\out_of_fold_predictions.csv
```

## 4. No-sleep sequence robustness

```powershell
py scripts/run_stage4_cleaned_robustness.py --data .\data\processed\haalsi_404_cleaned.csv --stage4-predictions .\results\results_cleaned_stage4\out_of_fold_predictions.csv --stage2-predictions .\results\results_cleaned_stage2\out_of_fold_predictions.csv --out .\results\results_cleaned_stage4_robustness
```

Check `--help` for exact CLI options before running; commands are based on the script interfaces and may need adjustment if the script's parser differs.

## 5. SHAP and LIME explainability

```powershell
py scripts/run_stage5_explainability.py --data .\data\processed\haalsi_404_cleaned.csv --out .\results\results_cleaned_stage5
py scripts/run_stage5_sensitivity.py --data .\data\processed\haalsi_404_cleaned.csv --out .\results\results_cleaned_stage5_sensitivity
```

## 6. Alternative MMSE scoring sensitivity

```powershell
py scripts/run_mmse_scoring_sensitivity.py --data .\data\processed\haalsi_404_cleaned.csv --audit .\data\audit\w1_participant_scoring_audit.csv --out .\results\results_mmse_scoring_sensitivity
```

## Notes

- These commands are a guide; verify each script's `argparse` options with `--help` before running.
- Existing `results/` files were supplied as saved outputs. They are not automatically regenerated by opening the package.
- Stage 4 cleaned-data code includes an extra duration-missingness channel relative to an earlier model version. Do not treat those runs as bitwise identical to earlier outputs.
- The MMSE sensitivity outputs in this archive were supplied with the package and the README says they have not been regenerated in this merged archive.
